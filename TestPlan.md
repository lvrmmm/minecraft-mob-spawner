# План тестирования: Minecraft Mob Spawner

**Проект:** Реализация спавнера мобов с паттерном "Абстрактная фабрика"

## Структура тест-кейсов

| ID теста | Название теста | Предусловия | Шаги выполнения | Ожидаемый результат | Статус |
|---|---|---|---|---|---|
| TC-01 | Создание фабрик для всех измерений | Установлена JDK, проект открыт в IDE | 1. Создать экземпляры `OverworldMobFactory`, `NetherMobFactory`, `EndMobFactory` | Все три фабрики создаются без ошибок | Pass |
| TC-02 | Спавн группы мобов в Overworld | Создана `OverworldMobFactory` и `MobSpawner` | 1. Передать фабрику в конструктор `MobSpawner` <br> 2. Вызвать `spawnMobGroup()` | В консоли появляются сообщения о спавне Зомби, Свиньи и Жителя с характерными звуками и действиями | Pass |
| TC-03 | Спавн группы мобов в Nether | Создана `NetherMobFactory` и `MobSpawner` | 1. Передать фабрику в конструктор `MobSpawner` <br> 2. Вызвать `spawnMobGroup()` | В консоли появляются сообщения о спавне Зомби-Пиглина, Хоглина и Пиглина | Pass |
| TC-04 | Спавн группы мобов в End | Создана `EndMobFactory` и `MobSpawner` | 1. Передать фабрику в конструктор `MobSpawner` <br> 2. Вызвать `spawnMobGroup()` | В консоли появляются сообщения о спавне Эндермена, Хорус-Коровы и Жителя Энда | Pass |
| TC-05 | Проверка метода `spawn()` у мобов | Создан любой конкретный моб (например, `Zombie`) | 1. Вызвать метод `spawn()` у объекта | В консоли выводится корректное сообщение: "Спавнится [имя моба] в [измерении]" | Pass |
| TC-06 | Проверка метода `makeSound()` у мобов | Создан любой конкретный моб (например, `Pig`) | 1. Вызвать метод `makeSound()` у объекта | В консоли выводится характерный звук для данного моба | Pass |
| TC-07 | Проверка метода `attack()` у HostileMob | Создан любой враждебный моб (например, `Skeleton`) | 1. Вызвать метод `attack()` у объекта | В консоли выводится сообщение об атаке, характерное для данного моба | Pass |
| TC-08 | Проверка метода `dropResource()` у NeutralMob | Создан любой нейтральный моб (например, `Cow`) | 1. Вызвать метод `dropResource()` у объекта | В консоли выводится сообщение о дропе соответствующих ресурсов | Pass |
| TC-09 | Расширяемость системы (добавление нового измерения) | Существует интерфейс `MobFactory` и абстрактные классы мобов | 1. Создать новую фабрику `NewDimensionFactory implements MobFactory` <br> 2. Создать новые классы мобов, расширяющие `HostileMob`, `NeutralMob`, `FriendlyMob` <br> 3. Протестировать создание | Новое измерение добавляется без изменений в существующих классах `MobSpawner`, `MobFactory` и других фабриках | Pass |
| TC-10 | Полная сборка и запуск программы | Все классы проекта написаны | 1. Выполнить команду `javac Main.java` <br> 2. Выполнить команду `java Main` | Программа компилируется без ошибок, в консоли появляется полный демонстрационный вывод для всех трёх измерений | Pass |
